Add them in Potensic Eve (iPhone)
  1. Open Potensic Eve, connect to the Atom 2 (firmware V020 or newer), tap Waypoints and start a new mission.
  2. Add waypoint 1, then 2, and so on, in the order above:
    • If Eve lets you type or paste a location, use Copy and paste the coordinates.
    • Otherwise, zoom Eve's map to the spot shown by the same numbered pin on the map above, and tap there.
  3. For every waypoint set height 30 m, camera -90° and action Take photo.
  4. Set the finish action to Return to Home, check that Eve's route matches the map above, keep the drone in sight, and tap Start.

Android users can also download the mission and load it into Eve automatically with the desktop app's Send to Atom 2.

Fly within visual line of sight and follow local drone rules. Eve limits height to 120 m above take-off.
